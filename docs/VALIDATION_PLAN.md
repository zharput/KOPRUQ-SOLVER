# Validation plan

Unit tests cover value validation and numerical primitives. Future phases add patch tests, benchmark problems, equilibrium checks, and regression comparisons with independently calculated reference results.
# Phase 2.2

Validation includes independent 18x18 references, rigid-body residuals and rank, orientation/coupling, boundary edge cases, component diagnostics, and repeated Release benchmarks.

# Phase 1

Validate 12x12 dimensions, symmetry, axial/torsional and bending coefficients, rigid-body modes, orthonormal axes, transformation orthogonality, and rejection of degenerate, non-positive, and non-finite inputs.

# Phase 3.1

Solver validation covers analytical cantilevers, torsion, inclined beams, independent portal references, sparse reduction, LDLT residuals, and Release warm-up/five-sample performance measurements.
